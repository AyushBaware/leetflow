# Privacy Policy — LeetFlow

LeetFlow does not collect, transmit, or sell any user data to the developer or any third party.

- Your GitHub token and repository settings are stored only in your browser's local extension storage and never leave your device except in direct, authenticated requests you initiate to GitHub's own API.
- Your LeetCode submission code and problem details are read from LeetCode's own responses to your browser and stored locally the same way, only until you push or replace them.
- LeetFlow has no backend server. No data passes through any server operated by the developer.
